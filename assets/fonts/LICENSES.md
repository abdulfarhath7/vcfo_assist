# Bundled fonts

All three families are licensed under the SIL Open Font License 1.1 and are
bundled here as latin woff2 subsets so the panel never loads a remote font.

- Manrope (variable 400–800) — © The Manrope Project Authors
- Space Grotesk (variable 400–700) — © Florian Karsten
- IBM Plex Mono (400, 500) — © IBM Corp.

The full OFL text is available at https://openfontlicense.org. If a file is
missing the stack falls back to system fonts.
